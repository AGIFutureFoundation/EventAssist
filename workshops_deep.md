## 1. Agents That Remember: Graph Memory in Production
### At a glance
- Speaker: Sara Kim | Time: 14:30 | Venue: Main Hall | Topics: Agents, GraphRAG
- Path: Sara Kim —GIVES→ Agents That Remember —ABOUT→ Agents / GraphRAG
- Plans: Ava Chen, Priya Nair

### Deep overview
Memory is not a chat log. In this graph, memory is four kinds of edges, all in one place: INTERESTED_IN (what you care about), MET (who you have already met), PLANS (what you intend to do), and the talk/topic links that explain why. A production agent does not re-ask you what you just told it, does not suggest someone you already met, and does not lose the plan when the session ends. That is the whole thesis of EventAssist, and this workshop is its proof case: if memory works, the concierge, networking, and schedule agents all get better from the same update, because they share the graph.
Learning flow: (1) memory as edges, not text; (2) memory across sessions — MET updates change future networking; (3) memory as explanation — show the path, don't just claim the answer; (4) memory in production — shared state, not a per-agent copy.

## 2. Multi-Hop Reasoning Without Hallucinating
### At a glance
- Speaker: Diego Ramos | Time: 15:15 | Venue: Room B | Topics: Agents
- Path: Diego Ramos —GIVES→ Multi-Hop Reasoning —ABOUT→ Agents
- Plans: Marcus Lee

### Deep overview
A question that needs two or three hops — speaker → talk → topic → attendee — is where language models hallucinate, because they can invent a hop that looks plausible. A graph cannot invent an edge that is not there. That constraint is the point: if there is no path, there is no claim, and if there is a path, you can show it. This workshop is the explainability workshop, and it is the one judges should press hardest on: ask a question, get an answer, then ask "how did you get that?" and expect a path, not a paragraph.
Learning flow: (1) one hop vs multi-hop; (2) path as proof; (3) missing edge as a honest "I don't know"; (4) multi-hop networking — shared topics through a topic node, not a similarity score.

- **Ava Chen, Marcus Lee, Priya Nair** — all Agents-interested, so all three are in the audience for this workshop in topic terms.
- **Marcus Lee** is the only demo attendee who plans this talk in the graph, and he is Agents-only — a focused, single-topic attendee, useful as a contrast to Priya's bridge role.
- **Tom Rivera** — not an Agents attendee, correctly excluded by topic.

### Real-contact segment

- **Sourcing / Procurement contacts** — angle: multi-hop supplier / product / company reasoning, with a path, not a guess.

### Deep overview
Turning documents into a knowledge graph, then answering from that graph instead of from raw text. Docs become nodes, relations become edges, and answers become paths you can audit.
